# onepunto-web

Web pública de [OnePunto](https://onepunto.com): portada y política de privacidad, en español e inglés.

HTML, CSS y un poco de JavaScript propio, sin dependencias ni rastreo. Se publica con GitHub Pages desde `main`.

La portada usa la paleta, la tipografía y las curvas de movimiento de la app: un punto que cae y rebota, la página que se despliega desde él, una cuadrícula que se completa al desplazarte y el cuadrado de la app para probarlo. Con movimiento reducido o sin JavaScript todo se ve igual, sin animaciones.

- `/` y `/en/`: portada.
- `/privacidad/` y `/en/privacy/`: política de privacidad. Es la URL que se da en Google Play; si cambia lo que la app hace con los datos, esta página se actualiza antes de publicar el cambio.

El código de la app vive en un repositorio privado aparte.
